# Manchester United Season Tracker

A python project that fetches  live Manchester United match data
from the football-data.org API and provides a full season analysis.

## Features
- Cumulative points graph with season comparison using matlib

## Requirements
- Python 3.x
- requests
- matplotlib
- python-dotenv

## Setup
1. Clone repository
2. Install dependencies: 'pip install requests matplotlib python-dotenv'
3. Create a '.env' file in the project root with your API key:
'API_KEY=your_api_key_here'
4. Get a free API key from https://www.football-data.org
5. Run the script: 'united_tracker.py'

## Data Source
This project uses the football-data.org API (free tier)
